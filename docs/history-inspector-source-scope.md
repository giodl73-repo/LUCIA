# LUCIA history inspector corresponding software source

The source ZIP is the complete buildable software workspace and browser
companion at the recorded Git commit: root Cargo.toml/Cargo.lock, both crates,
every tracked browser/inspector file, this document and the original LICENSE.
Paths and workspace inheritance are preserved. The native CLI and its core build
without any chapter/manuscript tree or TRACKER checkout.

This is not a full LUCIA repository or manuscript archive. Region chapters,
production/review/source/scoring/research material and retained external JSON
fixtures are excluded. Existing inline Rust unit tests remain part of the exact
software source. Synthetic browser example-history/profile JSON also supports
the native CLI's validate/compare commands. Full-checkout maintainer guards and
retained Mali fixture commands remain separate from standalone source builds.

Extract anywhere, including a path with spaces, and follow
browser/inspector/BUILD.md. The source build requires Rust 1.95.0, the pinned
bindings, Cargo registry dependencies and Node/Playwright for browser QA; these
are not vendored. Root and companion locks are included. No Git ancestry or
TRACKER-relative path is required for standalone builds.

The packaged source, public files, compiled WASM, dependency inventory, build
provenance and original notices have independent routes. Release qualification
rebuilds the delivered source outside Git, verifies that first-party dependency
paths remain inside the extracted tree, and replays both target outcome sets
and browser behavior. Binary identity across paths/platforms is not claimed.

Original grants remain intact: source code, scripts, tests, configuration and
ordinary software documentation are MIT; original non-software content remains
CC BY-NC 4.0 unless otherwise marked. No original chapter assets are added.
Third-party source and Rust library notices retain their own terms. The tool's
structural checks do not grant historical, chapter, manuscript or board authority.
